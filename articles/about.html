关于这个博客

你好，我是 42ium。

这个博客的存在只有一个目的：放一些带图片的小文章。没有评论、没有点赞、没有分析仪表盘——只有内容和读者之间的直接对话。

我崇拜的人

Steve Jobs 教会我：设计不只是看起来怎样，更是用起来怎样。真正的简洁需要砍掉那些看似必要实则多余的东西。

Linus Torvalds 教会我：好的东西经得起时间的审视。他创造了 Linux 和 Git——两个支撑着整个互联网运行的工具，而它们的内核哲学都是"把事情做对，而不是做多"。

技术

这个网站没有任何框架、没有构建工具、没有 JavaScript。只有手写的 HTML 和 CSS，通过 GitHub Pages 托管。

一行代码都不多写。这就是我理解的好设计。
